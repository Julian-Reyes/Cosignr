# Press photos

Only put photos here that the artist, their label or their management has given permission to use.

- Name each file after the artist's `id` in `data/artists.json`, e.g. `g-jones.jpg` (jpg, png or webp).
- Keep a note of who granted permission and when in `PERMISSIONS.md` in this folder.
- Run `node scripts/fetch-sources.mjs` afterwards so the site picks it up.
